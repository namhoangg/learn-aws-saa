# SAA-C03 study site

A personal study website built from the AWS Certified Solutions Architect – Associate
course slides: lessons in my own words with Mermaid diagrams and comparison tables, exam tips
and traps, spaced-repetition flashcards, scenario quizzes, a timed exam simulation, weak-area
practice and hands-on labs with cleanup checklists.

Deployed on Vercel from `main` (config in `vercel.json`). The course slides PDF and the
`_extract/` folder are personal study material: `.gitignore` keeps them out of the repo, so
they are never pushed or deployed.

## Run it

```bash
npm install
```

```bash
npm run dev
```

Then open http://localhost:5173.

## Where things are

| Path | What |
|---|---|
| `content/` | All study content (JSON + Markdown). Edit freely; see `content/README.md`. |
| `src/` | The React + TypeScript app (Vite). |
| `tools/` | Extraction, validation and progress scripts (below). |
| `PLAN.md` | Sections, slide ranges and the build plan. |
| `PROGRESS.md` | Build status of every section (generated by `tools/progress.py`). |
| `design/DESIGN_SPEC.md` | The UI design system the app implements. |
| `_extract/` | Text and page renders pulled from the PDF (local working data, not shown in the site). |

## Scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Start the site with hot reload (content edits reload too). |
| `npm run build` | Type-check and build a production bundle into `dist/`. |
| `npm run validate` | Check every content rule (structure, quiz keys, lab cleanup, Mermaid syntax). |
| `npm run validate -- --list-verify` | Also list every "Needs verification" item. |
| `npm run verbatim` | Flag text that copies the slides word for word. |
| `python tools/extract_pdf.py` | Re-extract slide text and renders, 50 slides per batch. |
| `python tools/progress.py render` | Refresh PROGRESS.md counts. |
| `python tools/merge_new_services.py` | Move services declared by sections into `content/services.json`. |

In the site, **Progress & settings → Content check** renders every section and reports broken
diagrams or Markdown after you edit content.

## Your progress

Stored in this browser's localStorage (lessons read, quiz history, quizzes in progress,
flashcard schedule, lab checklists), separately for each address: progress on
`localhost:5173` and on the Vercel site do not sync. Use **Progress & settings → Export
progress** to back it up or move it, and **Import progress** on the other site.
